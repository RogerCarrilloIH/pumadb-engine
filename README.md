# pumadb-engie
Sistema DBMS cliente-servidor en C para Linux. Implementa comunicación por sockets TCP/IP y procesamiento remoto de comandos SQL (SELECT, INSERT, UPDATE, DELETE) sobre archivos planos que simulan tablas relacionales.
